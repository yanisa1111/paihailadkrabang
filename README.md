# ตามหาป้ายทะเบียนน้ำท่วม ลาดกระบัง

## ขึ้นเว็บครั้งแรก (ทำครั้งเดียว)
1. เข้า github.com → New repository → ตั้งชื่อ เช่น `paihailadkrabang` → เลือก **Public** → Create
2. กด **uploading an existing file** → ลาก `index.html` กับ `plates.json` ใส่ → Commit changes
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/paihailadkrabang/`

## ลงป้ายใหม่
1. อัปโหลดรูปป้าย: Add file → Upload files → ตั้งชื่อไฟล์ภาษาอังกฤษ เช่น `kk1234.jpg`
2. เปิด `plates.json` → กดรูปดินสอ (Edit) → เพิ่มรายการตามตัวอย่าง → Commit changes
3. รอ ~1 นาที เว็บอัปเดตเอง

ตัวอย่าง `plates.json` (มีหลายป้ายให้คั่นด้วยจุลภาค `,`):

```json
[
  {
    "plate": "กข 1234",
    "province": "กรุงเทพมหานคร",
    "color": "ขาว",
    "area": "ลาดกระบัง",
    "place": "หน้าตลาดหัวตะเข้ ถ.ฉลองกรุง",
    "lat": 13.7262,
    "lng": 100.7584,
    "photo": "kk1234.jpg",
    "post": "https://facebook.com/...",
    "finder": "พี่สมชาย",
    "phone": "081-234-5678",
    "note": "ฝากไว้ที่สำนักงานเขตลาดกระบัง",
    "date": "2026-10-11"
  },
  {
    "plate": "1กค 5678",
    "province": "สมุทรปราการ",
    "area": "บางพลี",
    "place": "ริมคลอง ซ.5"
  }
]
```

- `province` = จังหวัดที่**เขียนอยู่บนป้าย** (ไม่ใช่จังหวัดที่เจอ) — ควรใส่ทุกครั้ง เพราะเลขทะเบียนเดียวกันซ้ำกันได้ถ้าคนละจังหวัด เช่น กข 1234 กรุงเทพฯ กับ กข 1234 สมุทรปราการ เป็นรถคนละคัน ถ้าอ่านจังหวัดไม่ออกให้ลบบรรทัดนี้ แล้วเขียนไว้ใน `note`
- `color` = สีป้าย ใส่ได้ `ขาว` `เขียว` `เหลือง` `น้ำเงิน` `แดง` (ถ้าไม่ใส่ถือว่าขาว) — เว็บจะแยกเป็นแท็บตามสี
- `area` = เขต/อำเภอที่เจอป้าย เช่น ลาดกระบัง, ประเวศ, มีนบุรี, หนองจอก, สะพานสูง, บางพลี (ถ้าไม่ใส่ เว็บจะถือว่าเป็นลาดกระบัง)

- ตัวอักษรที่อ่านไม่ออกให้ใส่ `x` เช่น `6ขx 4049` และใส่ `"unsure": true` เว็บจะขึ้นป้าย "⚠️ ไม่แน่ชัด"

ช่องไหนไม่มีข้อมูล ลบบรรทัดนั้นทิ้งได้ ยกเว้น `plate` (ถ้าโพสต์ไม่บอกสถานที่ ไม่ต้องใส่ `place` เว็บจะขึ้นว่าให้ทักผู้โพสต์ต้นทาง)
